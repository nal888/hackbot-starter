# Session index

The transcript is the detailed record of the session. Record its location as
well as its ID so you can find it later. Add separate rows for worker sessions
and link them to the main session when that relationship is available.

| Date | Tool / version | Session or worker ID (label which) | Parent session, if any | Original log path | Readable export / exported at | Question / note |
| --- | --- | --- | --- | --- | --- | --- |

If no transcript was saved or an ID is unavailable, say so. Don't reconstruct
missing history from the final summary. Store private exports locally; review
them before sharing.
